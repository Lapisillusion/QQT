# 道具实施与验收记录

日期：2026-10-17。四类道具、局部观察计算、脚本断言、日志、UI 已实施。本文记录实际运行结果，规则与场景清单见 [实施计划](道具需求与实施计划.md)。

## 1. 交付范围

- 四类 +1 增益：速度、容量、每方向范围、视野半径。默认视野 R=2，获取后下一轮 R=3，内部位置观察 25→49 格；地图边缘裁剪，墙箱不遮挡。
- 道具开局只存在于初始箱子中，每格一件。支持固定位置／类型数组或各类型数量的随机分配；位置不足时按剩余需求加权选择并跳过未满足需求。
- 箱毁后露出；原有露出道具会被爆炸销毁，同批新露出者保留。存活玩家到中心拾取，同刻多人都获得，同刻先结算爆炸与终局。
- 拾取只累计待生效增益；PrepareRound 在下一轮计划校验之前激活。旧轮终点使用旧属性，下一轮已放泡泡也使用所属玩家新范围。
- 玩家局部观察与全局 UI 分开：前者仅返回视野内地形、可见其他玩家编号／位置、泡泡轮内查询编号／位置和露出道具的位置／类型／效果；自身状态完整。隐藏与视野外信息不返回。
- 观察独立持有租用数组，跨世界推进及重跑保持稳定；调用者完成后 Dispose，禁止归还后访问。包装对象和 JSON／框架仍可能分配，不声称消除了所有 GC。
- UI 按精确事件播放道具露出、销毁、拾取及增益，面板显示已生效属性和待生效增益；S／C／R／V 对应四类道具。
- 新增脚本位于 scripts/items；构建递归复制 JSON 并保留目录。日志增加 QQT.Simulation.Tick.Item，含分配、露出、销毁、拾取、属性激活及最终状态。

真实 AI 接入、查询计费、玩家视野切换预览、持久化回放、暂停／单步和 500 tick 上限仍未实现。原正式默认地图、默认参数和安全脚本保持原配置；未指定四类道具的玩法默认数量。

## 2. 配置与调用

脚本顶层 items 完整覆盖 appsettings 的 Items，不逐字段混合。均未配置则不生成道具。

```json
{
  "items": {
    "mode": "fixed",
    "placements": [{ "position": { "x": 2, "y": 0 }, "type": "vision" }]
  }
}
```

随机模式提供 mode=random、可选 int 种子 seed，以及 counts.speed/capacity/range/vision 四个非负 int 数量。实际种子与每类请求、生成、跳过数量均记录；总量求和使用 long，最多分配初始箱子数次，不为过量请求构造类型数组。类型枚举与箱子按固定顺序处理，相同地图、配置、种子可复现。

固定模式拒绝非箱子、越界、重复位置和未知类型；随机模式拒绝负数量、缺少类型数量及未知类型。两种模式不能混用字段。箱子不足属于正常结果，不报成运行故障。

独立观察 API 为 PrepareRound → Observe(playerId)；观察仅对存活玩家、已准备的新轮开放。脚本 expected.observations 指定 roundId、playerId、cellCount、vision、items，另可检查 self、cells、absentCells、players、bubbles。只有声明的轮次实际检查完成才算通过，提前终局不能漏验。

expected.players 及 checkpoints 可断言 speed/capacity/range/vision 和四项 pending；expected.items 精确核对所有初始分配的位置、类型与最终 hidden/exposed/destroyed/picked 状态。expected.events 支持 itemType、value、roundId、phase 筛选，区分旧轮终点与下一轮激活。

## 5. 浏览器实际结果

真实本机无头 Chrome／Playwright 实际运行 02、05、06、07、12、14 六个场景，每个两次，runId 均变化，页面错误为 0。核对连续事件序号、WebSocket 最终状态、DOM 验证结果、道具终态与属性。

- 02：隐藏道具没有绘制，重跑后相同种子分配相同。
- 05：画布先绘制 S，后续另一批爆炸移除 S 并绘制 C，采样时间有明确先后。
- 06／07：回退未重复拾取，同刻两人的待生效视野均为 1。
- 12：面板显示视野 R=3，服务端观察断言通过。
- 14：S、C、R、V 分别在不同中心拾取时刻从画布消失；待生效增益和下一轮已生效属性均有实际 DOM 变化；终局、遗留泡泡和重跑清理正确。已查看中途与最终截图，布局正常。

浏览器推进间隔为 1200ms、动画为 1000ms，便于采样；只改变现实播放，源默认配置仍为 1000ms，不影响精确逻辑时间。采样器首次误将地图列名 S/C/R/V 计作道具，随后限定为道具绘制样式并重跑六项通过；该首次失败属于验证工具，未作为产品通过结果。
