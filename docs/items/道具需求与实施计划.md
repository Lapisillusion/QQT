# 道具需求与实施计划

日期：2026-10-17。状态：已实施并完成本次验收，实际结果见 [道具实施与验收记录](道具实施与验收记录.md)。

规则依据为 [已确认首版规则](../首版模拟规则_已确认版.md)，最新用户确认优先。本文保留实施前的设计与场景清单；当前完成情况和实际命令以验收记录为准。

## 1. 已确认范围

| 道具 | 每次获取的效果 |
| --- | --- |
| speed | 移速 +1 格/tick |
| capacity | 同时在场泡泡容量 +1 颗 |
| range | 每方向爆炸范围 +1 格 |
| vision | 视野半径 R +1 格；未裁剪时 5×5 → 7×7 |

- 四类道具开局仅预藏于初始箱子，每格至多一件，不在箱子被破坏时临时随机抽取。
- 支持固定位置、类型数组，以及各类型随机数量配置。随机总数超出箱子数时尽可能放满；按剩余需求数量加权随机选择类型，位置耗尽后跳过剩余需求。
- 箱子破坏后道具露出；只有玩家视野内的露出道具免费显示位置、类型和效果，隐藏内容及视野外信息不下发给玩家。
- 玩家存活且到达中心时拾取；同刻多人到达同一道具中心，都获得一次增益，再统一移除道具。
- 增益从下一轮生效，可累积、持续至局末、无游戏属性上限。本轮速度、容量、范围和冻结观察不改变。
- 爆炸销毁此前已露出的道具；同批刚从箱子露出的道具保留。拾取与爆炸同刻时，先爆炸和淘汰。
- 已放泡泡按实际爆炸所属轮的已生效范围计算；旧轮终点仍使用旧范围。
- 本次实现局部观察计算和脚本验证，观战 UI 展示道具及玩家属性。真实 AI 接入、查询计费、持久化回放、视野切换预览不在本次范围。

## 3. 配置设计

采用显式 `items.mode`，固定和随机互斥，避免混合配置引入顺序含义。该字段组织是实现选择。

固定模式示例：

```json
{
  "items": {
    "mode": "fixed",
    "placements": [
      { "position": { "x": 2, "y": 0 }, "type": "vision" }
    ]
  }
}
```

随机模式示例：

```json
{
  "items": {
    "mode": "random",
    "seed": 12345,
    "counts": { "speed": 3, "capacity": 3, "range": 3, "vision": 3 }
  }
}
```

示例数量不是玩法默认值，各类型实际数量仍由配置明确给出。遗漏整个 items 配置时不生成道具，保证现有脚本的初始条件稳定；显式随机模式要求四类数量均为非负整数。

- 对局配置可提供 items，脚本可完整覆盖本局 items；缺省继承，不逐字段合并。旧默认配置不启用道具；脚本可用四类全零配置明确关闭。
- 初始化顺序：Reset → 可选测试环境 Configure → 校验并生成本局道具 → 发布初始状态。正式地图和测试地图使用同一分配与结算代码。
- 固定位置必须在地图内、是初始箱子、无重复，类型必须已知。非法配置拒绝创建，不静默挪位。
- 随机模式的箱子不足是正常结果，不算失败；负数量、未知类型或模式字段冲突是配置错误。
- 随机种子未提供时生成并记录实际种子；指定相同种子、相同地图和配置时复现分配。重跑重建状态，不复用已推进的随机源。
- 随机分配使用箱子位置池数组、四类剩余计数和加权抽样；不按请求总量构造类型列表。数量求和采用宽整数，循环上限受可用箱子数量约束。
- 每局记录模式、种子、请求数量、实际数量、跳过数量及实际位置、类型。未来回放读取实际分配，本次不扩展回放系统。

## 4. 状态和精确结算

按格保存道具类型及隐藏／露出状态，与地形分开。小型记录采用值类型；玩家分别保存已生效属性和待生效增益，不修改本局初始配置。

每个分数事件时刻按以下顺序结算：

1. 推进质点，按处理前环境统一判跨线。
2. 从同一份旧地图计算全部到期、连锁和覆盖。
3. 先销毁覆盖内原有露出道具，再销毁箱子并露出其道具；同批重叠射线不销毁新露出者。
4. 合并淘汰并立即判胜负；终局即停止后续拾取、放置和移动。
5. 对存活且到达中心的玩家按道具批量确定全部获得者，累计待生效增益后移除道具。
6. 执行本轮已生效容量允许的放置，再继续本轮移动或回退。

拾取独立于放置请求；覆盖高速经过中心、轮初中心及回退到中心等路径。同一轮内已移除道具不重复发放。拾取不引入新的决策点或固定小步模拟。

旧轮终点完成后，新轮准备阶段统一激活增益，生成冻结观察，再校验新轮路径与计划。不能在仍用旧速度校验计划后才激活；也不能在旧轮终点爆炸前激活。轮次与阶段区分同一物理时刻，避免重复应用。

若终局或脚本验收结束且未开启新轮，待生效增益保留在对应阶段状态，不假装已经应用。死亡玩家及其存量泡泡的属性处理继续遵循首版规则；重点核对其已放泡泡仍使用正确轮次的所属玩家属性。

容器租用、扩容、异常归还及异步消息生命周期按 AGENTS.md 执行；每轮和每帧不重建全部道具状态。

## 5. 观察、日志与 UI

- 局部观察以玩家归属格为中心，用本轮已生效 R 裁剪方形和地图边界；墙、箱子不遮挡。
- 新轮冻结观察保持稳定；后续模拟及池缓冲复用不能改写仍被验证或消费者持有的观察。
- 玩家观察和全局 UI 分开投影。玩家可见道具仅含露出且位于视野内者；可见其他玩家和泡泡继续遵守原免费信息边界。
- UI 快照包含道具状态、玩家已生效属性和待生效增益；全局观战权限不作为玩家观察数据源。
- 新增生成、露出、销毁、拾取、属性激活事件。UI 按精确时间播放，不提前绘制轮末道具，也不因只收到轮末快照遗漏本轮出现后又消失的道具。
- `QQT.Simulation.Tick.Item` 记录位置、类型、玩家、轮次、阶段、精确时间、属性前后值；信息日志记录关键事件，逐位置分配细节使用 Debug／Trace。位置不足记录分配摘要，不当作运行故障。
- 扩展脚本断言，核对道具终态、事件次数与时间、待生效／已生效属性以及指定轮次观察内容，避免只检查“验证通过”文本。

## 6. 实施顺序与验收

| 步骤 | 交付 | 验收条件 |
| --- | --- | --- |
| 1 | 配置、道具状态及初始化 | 固定位置准确；随机一格一件，数量充足时精确满足；不足和零箱子正确跳过；种子复现；非法配置拒绝 |
| 2 | 露出、销毁及中心批量拾取 | 跨线不拾取、中心拾取；高速路径正确；同刻多人均获得；同刻爆炸优先；新掉落保留，后续爆炸销毁 |
| 3 | 下一轮属性激活 | 本轮不变；下轮速度与容量生效；旧轮终点旧范围、新轮存量泡泡新范围；连续拾取可累积且无重复应用 |
| 4 | 局部观察及视野道具 | R=2→3 时内部位置 25→49 格；边缘裁剪；墙不遮挡；隐藏与视野外道具不泄露；新轮才扩大观察 |
| 5 | 日志、快照与 UI | 四类道具能识别；属性与待生效状态一致；露出、拾取、销毁按精确时间播放；重跑无残留 |
| 6 | 集成与回归 | 递归复制后的子目录脚本可从构建输出运行；旧四份 M0 和精确时间关键边界回归通过 |

新验证脚本统一放在 `scripts/items/`，每份先写独立输入和预期，再运行实际服务端 --verify，按日志核对，不从实际输出回填预期。优先用脚本覆盖上述可区分的关键风险，不为每个字段或组合增加独立测试。

### 6.1 新增 14 份道具脚本

均放在 `scripts/items/`。共 14 份正式新增脚本，复跑及 UI 播放使用同一文件，不重复计数；每份声明完整初始环境、四人计划和独立预期。

| 文件 | 主要目的 |
| --- | --- |
| `items-01-fixed-hidden.json` | 固定位置与四类道具准确预藏，每格一件；箱子未毁时玩家观察不泄露内容 |
| `items-02-random-seeded.json` | 箱子足够时满足各类数量、位置不重复；同地图配置和种子复跑得到同一分配 |
| `items-03-random-overflow.json` | 需求超过箱子数时按剩余数量加权抽样，放满后跳过剩余需求；独立预期核对确定种子的分配与各类计数 |
| `items-04-random-no-crates.json` | 无箱子时所有需求跳过、生成零件道具，初始化与正常推进均不失败 |
| `items-05-explosion-lifecycle.json` | 箱子破坏后露出；同批重叠／连锁覆盖不销毁新露出道具，后续另一批爆炸可以销毁 |
| `items-06-center-pickup.json` | 高速跨线不提前拾取，到中心才拾取；沿途多件逐次获取，随后遇阻回退不重复发放 |
| `items-07-shared-pickup.json` | 同刻多人到同一中心，各自得到一次增益，道具仅移除一次，不依赖玩家遍历顺序 |
| `items-08-blast-before-pickup.json` | 中心到达与爆炸同刻先销毁、淘汰；死亡者不能拾取；同刻终局后不再拾取 |
| `items-09-speed-activation.json` | 移速本轮不变，下轮才改变实际轨迹、计划距离和到达时间；多次拾取累计 |
| `items-10-capacity-activation.json` | 本轮满容量不能因刚拾取而额外放置；下一轮扩容允许增加在场泡泡，计数正确 |
| `items-11-range-activation.json` | 旧轮终点仍按旧范围爆炸；下一轮此前已放泡泡按新范围到期或连锁，覆盖与淘汰一致 |
| `items-12-vision-activation.json` | 内部位置 R=2→3 后下一轮观察由 25 格增至 49 格；本轮冻结观察稳定，视野外实体不提前泄露 |
| `items-13-vision-clipping.json` | 地图边缘正确裁剪；墙箱不遮挡，视野内露出道具显示完整免费信息，隐藏和视野外道具仍不提供 |
| `items-14-integrated-rerun.json` | 四类道具串联完整对局，核对精确事件、属性和终局；浏览器播放与服务端一致，重跑清除道具、待生效增益和旧事件 |

其中随机脚本核对确定种子的独立结果和数量约束，不用少量采样声称证明统计公平性。加权选择是否按剩余数量计算，同时通过实现审查确认。
