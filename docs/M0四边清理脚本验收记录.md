# M0 四边清理脚本验收记录

日期：2026-10-15。

## 输入与独立预期

新增脚本 `scripts/m0-perimeter-clear.json`。保持正式 21×21 地图、固定四角绑定、速度 1、容量 3、范围 1、寿命 3 tick。四条外边各有 17 个箱子，共 68 个。

| 玩家 | 负责的外边／路线 | 完成后位置／结果 |
| --- | --- | --- |
| P1 | 上边 A1→U1 | U1，t=108 自爆死亡 |
| P2 | 右边 U1→U21 | U21，t=108 自爆死亡 |
| P3 | 左边 A21→A1 | A1，t=108 获胜 |
| P4 | 下边 U21→A21 | A21，t=108 自爆死亡 |

每人沿所负责边依次在距出生点 1～17 格的位置放置泡泡，放置时刻为 t=1、7、13、…、97，分别在 t=4、10、16、…、100 爆炸。第一次放置后回到出生点，再到出生点另一相邻空格避险；后续每次放置后退两格，等待爆炸，再向前推进。不同玩家不进入其他人的爆炸范围。

- t=100：四条边箱子全部清空，四人存活，在场泡泡 0。爆炸向内同时清掉 32 个箱子，共销毁 100 个箱子；其他箱子与全部硬墙保留。
- t=105：四人到达各自负责边的另一个角落。
- 第 106 轮起点是 t=105，P1、P2、P4 各放一颗泡泡并原地等待，P3 等待且不放置。
- t=108：三颗泡泡到期，P1、P2、P4 统一淘汰，各一次死亡、死亡时自有泡泡数为 0；P3 在 A1 获胜并立即结束。
- 最终放置 71、引爆 71、销毁箱子 100、剩余箱子 229、硬墙 100、泡泡 0。脚本 `expected` 独立列出全部 71 颗泡泡的归属／位置／放置／到期／爆炸时间、100 个箱子坐标和四人终态，不从运行结果反填。

JSON 的 `notes` 为人读说明，执行仍使用既有 `rounds` 与 `expected` 格式，没有增加脚本语言或运行参数。

## 经确认的容量调整

原常规入口只允许 8 轮、历史固定 256 条，不能执行本场景。向用户说明后，用户明确选择“允许同步放宽轮数和事件历史限制，使常规入口也能运行”。因此除新 JSON 外，做了必要的容量调整：

- `Scenario.MaxScriptTicks` 默认从 8 提高到 128，默认脚本与 1000ms 播放配置保持原值。
- 核心单轮上界仍为 96，仅提取为共享常量 `GameSimulation.MaxEventsPerTick`。
- runner 历史按允许轮数乘单轮上界从数组池租用，默认有效容量 12288。检查使用有效容量，池可能返回更大数组不代表额外允许长度；不截断历史。
- 历史由 runner 唯一持有，跨重跑复用，事件发送使用既有独立消息缓冲，在运行与发送结束后的 DisposeAsync 中归还。没有引入新容器池或扩大游戏规则。

128 是脚本工具限制，不是完整竞技的 500 tick 规则。

## 实际验证

- `dotnet build QQT.sln --no-restore` 通过，0 警告、0 错误。
- 常规 `--verify` 入口执行新脚本，返回 0：Tick=108、WinnerId=3、Placed=71、Exploded=71、Destroyed=100、Crates=229、Walls=100、Bubbles=0；MapMatches、PlayersMatch、BubblesMatch、ActionsMatch、OutcomeMatches 均为 True。
- 原安全、死亡、连锁获胜三个脚本回归均返回 0，原位置、计时、计数及结束结果保持正确。
- 仅将测试进程的 MaxScriptTicks 设置为 107 后，新脚本返回 1，明确拒绝“脚本轮数必须在 1～107 之间”，确认上限校验仍有效。
- 使用本机已有 Playwright／Chrome 打开常规 UI，点击开始完整播放，再点击重新运行。两次均收到全部 108 轮状态，两个 RunId 不同，页面脚本错误为 0。
- 对 t=100 帧逐格检查全部外边均为空地，四人存活、泡泡 0；箱子销毁事件共 100 个，其中外边 68 个，明确满足“先清边、后故意输掉比赛”。
- 对终局逐项核对 DOM、UI WebSocket 和 JSON 预期，全部一致；事件 sequence 连续 1～915，71 次放置、71 次唯一爆炸、3 次死亡，最后一个事件为比赛结束，没有 t>108 的状态。显示面板排除 245 条逐格覆盖事件后为 670 条日志，完整数据仍保留全部 915 条。
- 已查看实际终局截图：四条外边清空，P3/A1 存活，另外三角角色死亡；显示 t=108 获胜、箱子 229、在场泡泡 0、存活 1。
- 浏览器测试进程以环境变量将推进与动画都设为 200ms，仅缩短现实播放，逻辑时间和源配置不变。正常默认播放约 108 秒。
