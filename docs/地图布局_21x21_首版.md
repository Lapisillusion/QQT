# 首版固定地图：内部 21×21

本图按已确认规则生成。人读坐标为列 A～U、行 1～21，A 为第 1 列。协议使用从 0 开始的整数对 (x,y)，JSON 为 {"x":0,"y":0} 对象形式，x 向右、y 向下：A1=(0,0)，B2=(1,1)，U21=(20,20)。人读偶数行列交点的硬墙，对应协议坐标 x、y 同时为奇数。

- 行、列序号同时为偶数的交点是不可破坏墙：B2、D2…T2，B4、D4…T4，直到 T20。
- 四角 A1、U1、A21、U21 是出生点，其两个向内相邻格为空地。
- 除硬墙和预留空地外，其余全部为可破坏箱子。
- 每局恢复此初始布局，按配置的 2、3 或 4 名玩家，从四角随机选取互不重复的出生点并一对一分配，由服务端保存种子和实际分配用于复现。未使用的角不生成玩家，地图与四角预留空地保持不变。
- 三类道具按每局配置数量随机预藏于不同箱子，每箱最多一件，数量总和不超过 329；箱子被毁后才露出。该分配不改变下面的地形数量，AI 观察不显示箱内隐藏内容，实际分配保存于记录。
- UI 在外围额外画一格厚硬墙，整体可视格位为 23×23；该外圈不占逻辑地图格。
