# M0 实施与验收记录

日期：2026-10-13。

## 已实现

- 两个 .NET 10 项目：Core 模拟和 Server 宿主；TypeScript 前端独立编译，ASP.NET Core 提供页面与 UI WebSocket。
- 固定 21×21 地图、四角绑定、四轮 JSON 脚本；每轮一格移动、阻挡检查、泡泡格离开、终点放置、寿命计时、范围覆盖、箱子销毁和受击安全检查。
- 完整同刻覆盖先按旧地图计算，再统一移除泡泡和箱子；场景四轮后检查结果，不判竞技胜负。
- 浏览器全图、服务端移动段动画、泡泡倒计时、爆炸效果、玩家状态、关键事件日志，以及开始／重跑。
- 按系统分类的日志、关键日志源生成；状态与临时数据池化，异步消息发送完成再归还。
