## 当前阶段的工作原则

基础模拟机制已足够开始验证。先跑通模拟核心、正式地图、预设脚本、全局 UI 和暂停／继续／单步；真实 AI 接入、查询计费与记录回放仍按首版已确认范围继续完成。实施顺序不缩减首版范围。

首期包含三种道具：移速 +1 格/tick、同时在场泡泡容量 +1 颗、每方向爆炸范围 +1 格。按配置数量开局随机预藏到不同箱子，破坏后露出；中心拾取，同刻到达者都获得。旧轮终点处理后，下一轮生效，增益持续至局末、可累积且无上限。此前已放泡泡也按爆炸轮的已生效范围计算；视野内露出道具免费显示位置和类型。爆炸销毁原有露出道具，同批新掉落者保留。初始属性不变，各类道具的初始数量尚未指定，详见规则汇总。

字段、目录、界面排布等可修改的细节由实现时采用简单方案并记录，不逐项问答。只对影响核心机制、公平性或实现范围的新歧义继续确认。

运行后再根据结果评估玩法平衡、信息查询的策略价值与成本，以及 UI／单步／日志的排查效果；这些评估不预先更改已确认规则和参数。
