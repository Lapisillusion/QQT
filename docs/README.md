## 当前阶段的工作原则

基础模拟机制已足够开始验证。先跑通模拟核心、正式地图、预设脚本、全局 UI 和暂停／继续／单步；真实客户端协议、查询计费与对战流程已完成本次验收；独立暂停／继续及记录回放界面仍按首版范围继续完成。实施顺序不缩减首版范围。

首期包含四种道具：移速 +1 格/tick、同时在场泡泡容量 +1 颗、每方向爆炸范围 +1 格、视野半径 R +1 格（5×5 → 7×7）。开局按固定位置或随机数量配置预藏到不同箱子；随机位置不足时按剩余需求数量加权分配，剩余跳过。箱子破坏后露出；中心拾取，同刻到达者都获得。旧轮终点处理后，下一轮生效，增益持续至局末、可累积且无上限。此前已放泡泡也按爆炸轮的已生效范围计算；只在玩家视野内免费显示露出道具的位置、类型和效果。爆炸销毁原有露出道具，同批新掉落者保留。初始属性不变，各类道具的实际配置数量尚未指定，详见规则汇总。

2026-10-17 已实现四类道具、局部观察计算、脚本验证及 UI 道具／属性展示。14 份新增脚本与 12 份既有回归通过，6 个浏览器场景各运行两次通过；实际输入、预期与证据见 [道具实施与验收记录](items/道具实施与验收记录.md)，设计和场景清单见 [实施计划](items/道具需求与实施计划.md)。真实 AI 接入与玩家视野切换预览不在本次范围。

字段、目录、界面排布等可修改的细节由实现时采用简单方案并记录，不逐项问答。只对影响核心机制、公平性或实现范围的新歧义继续确认。

运行后再根据结果评估玩法平衡、信息查询的策略价值与成本，以及 UI／单步／日志的排查效果；这些评估不预先更改已确认规则和参数。
